# 语言与失效文件回归验证

请在隔离的测试数据上执行；失效文件窗口中的“删除记录”会移动记录到回收站。

1. 选择 English，关闭并重新启动应用。检查启动加载文字、带数字的扫描和图标进度、菜单、收藏及最近访问标签均为英文；无需打开设置。切换回简体中文并重复检查。
2. 在运行时反复切换语言，检查主窗口、已打开的失效文件窗口和通知同步更新。自定义标签名称不应被翻译或写回数据库。
3. 测试旧配置：分别仅保留 `System/LanguageIndex=1` 和 `System/Language=en-US`，启动后应使用英文并迁移到 `LanguageCode`；同时存在时以 `LanguageCode` 为准。
4. 准备可用文件、源文件失效但备份可用的记录、源文件和备份均失效的记录，以及没有备份的记录。等待后台检查结束：仅确认失效的记录计入左下角通知，数量应准确；没有失效项时不显示通知。
5. 点击通知中的“查看”，确认列表、分类、备份警告和按钮；关闭通知后，通过文件菜单中的“失效文件”仍可打开。没有失效项时菜单入口应显示空状态。
6. 选择“稍后再说”和“使用备份”不应删除记录；使用备份后，可用备份应仍可打开。选择“删除记录”后检查回收站及重新检查的数量；无可用备份时“使用备份”应禁用。
7. 检查过程中关闭窗口或连续打开入口，不应重复弹窗或因取消任务而崩溃；检查失败时不应误报为空列表。
8. 在浅色、深色主题及较大字体下检查加载图标和通知按钮的可见性。语言文件自定义翻译应在重载后保留。
